# DAA Lab — Design and Analysis of Algorithms

Lab programs implemented in Python, covering core algorithm design techniques taught in the DAA course.

## Contents

| # | Folder | Topic | Description |
|---|--------|-------|-------------|
| 1 | `1_SortingAlgorithms` | Sorting | Bubble, Insertion, Selection, Merge, and Quick Sort |
| 2 | `2_SearchingAlgorithms` | Searching | Linear Search and Binary Search (iterative + recursive) |
| 3 | `3_HeapSort` | Heap Sort | Build max-heap and sort using heapify |
| 4 | `4_Factorial` | Recursion | Factorial using recursive and iterative approaches, with time comparison |
| 5 | `5_Knapsack` | Dynamic Programming | 0/1 Knapsack problem using DP table |
| 6 | `6_MatrixChainMultiplication` | Dynamic Programming | Optimal parenthesization for matrix chain multiplication |
| 7 | `7_CoinChange` | Dynamic Programming | Minimum coins needed and number of ways to make an amount |

## How to Run

Each folder contains a single Python file. Run any program with:

```bash
python <folder_name>/<file_name>.py
```

Example:

```bash
python 1_SortingAlgorithms/sorting.py
```

## Requirements

- Python 3.x (no external libraries needed)
